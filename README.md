# Halloween Text-Based Adventure 

**Imports**
All imports apart from playsound are a python standard import already included. Please run this command before running the script.
> pip install playsound==1.2.2

# How to run

**Github CLI**
>gh repo clone maxfowlercodes/Halloween-text-adventure- 


**Git installed**
>git init, git pull https://github.com/maxfowlercodes/Halloween-text-adventure-.git main
